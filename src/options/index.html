Memory

Navi keeps one short note about you, your preferences and your projects, and reads it before each request. It's updated in the background, when Navi is idle, from what you tell Navi (never from web pages), and only sent to your AI provider with requests. On by default in Pro; Free and Pro each have their own switch.

Edit it like any text, or just tell Navi (“remember I'm vegetarian”, “forget my old address”).

Listening

You say “Hey <name>” once to wake Navi. Distinctive names with two or more syllables trigger by accident less often. With the name Navi, “Hey Navigator” works too: speech recognizers rarely mishear it.

Both run on this computer. Parakeet runs on the graphics chip when there is one; while it downloads or loads, Chrome's recognizer listens. English and 24 European languages.

Chrome's recognizer runs on this computer (Chrome 139+; download it on the setup page). Navi never uses Google's cloud speech service.

Voice

Kokoro, a neural voice that runs on this computer, so replies never leave it: on the graphics chip when there is one (a 326 MB download), otherwise on the processor (92 MB, a bit slower). It downloads once, the first time Navi speaks, or from the setup page.

For both voices; 1 is Navi's normal pace. “Talk faster” and “talk slower” change it too.
