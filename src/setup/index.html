Set up Navi

Navigate Chrome with your voice. This takes about a minute.

1. Allow the microphone

Chrome only lets extensions ask for the microphone from a normal tab like this one, so Navi asks once here.

2. Keep your voice on this computer (recommended)

Newer versions of Chrome can recognize speech on-device, so audio never leaves your laptop, even while Navi listens for its name. Otherwise Chrome uses Google's speech service.

3. Open Navi

Click the Navi icon in the toolbar (pin it from the puzzle-piece menu), or press Alt+Shift+N. Navi opens in the side panel.

4. Say “Hey Navi”

Navi wakes up and stays awake while you keep giving commands, so you only say its name once. It goes back to sleep after two quiet minutes, or when you say “go to sleep”.

Basic commands (scrolling, tabs, opening sites, “click 5”) work right away. For everything else, add a Claude API key in settings.
